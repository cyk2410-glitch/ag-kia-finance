# AG 천팀장 기아자동차할부 홈페이지 배포 안내

## 배포
1. 이 ZIP을 압축 해제한 뒤 **전체 폴더**를 GitHub 저장소에 업로드하세요. `index.html`, `netlify.toml`, `netlify/functions/latest-posts.js`, `assets` 폴더를 함께 유지합니다.
2. Netlify에서 GitHub 저장소를 연결하고 빌드 명령은 비워 둡니다. Publish directory는 `.`이며 Functions directory는 `netlify/functions`입니다.
3. Netlify에 배포된 주소가 확정되면 `index.html`에 canonical, og:url, 절대경로 og:image를 반영하고 `sitemap.xml`에 실제 도메인을 입력하세요. 그 뒤 검색엔진 사이트맵을 제출하세요.
4. `https://배포주소/.netlify/functions/latest-posts`를 열어 `posts` 배열이 최신 6건으로 표시되는지 확인하세요. 두 블로그 모두 접근 가능한지 `warnings`를 확인합니다. 이후 새 게시글 발행 시 자동 반영을 재확인합니다.
5. PC·모바일 메뉴/22개 모델 필터/4개 사례 링크/카카오톡/전화/유튜브/이미지/파비콘을 점검합니다.

## 중요 확인 사항
- 원본 현대차 홈페이지에 사용된 `assets/ag-unified.png`는 전달되지 않았습니다. 이 파일은 제공받은 `profile.jpg`에서 만든 임시 대체본입니다. **기존 AG 원형 통합 대표 아이콘 원본을 받으면 교체해야 합니다.** 파비콘은 전달된 원본 `.ico`를 유지하고 나머지 PNG 규격은 이 파일에서 변환했습니다.
- `latest-posts.js`는 이번에 새로 작성한 공개 RSS 수집 함수이며 실제 Netlify 배포·Naver RSS 연결 성공은 아직 검증되지 않았습니다. RSS가 차단되거나 비공개인 경우 화면에 오류 안내가 나타납니다.
- EV5 원문: 차량가 4,916만원, 승인 2,516만원, 부족금 2,406만원 기재. 산술상 차액은 2,400만원이므로 홈페이지는 계산 차액으로 표시했습니다. 원문 확인 후 정정하세요.
- 카니발 하이브리드 원문: 필요 자금 5,189만원, 승인 3,000만원, 플랜B 2,161만원, 탁송료 28만9천원 별도. 항목별 금액 관계를 확인해야 합니다.
- 모델 22개는 전달된 기획안 기준이며 현재 판매 모델/금융 대상 여부는 공식 자료와 개별 심사로 확인해야 합니다.
- 기존 현대자동차 홈페이지에는 영향을 주지 않는 별도 배포본입니다.
